Bio

About

I write software for work that already has rules: money, time, records, and the people who have to live with the result. I would rather ship a small system that holds its invariants than a large one that hopes for the best.

Recent work includes Chrono, a legal billing prototype with lodestar reporting, and this site — a deliberately small public face for new projects.

How I like to work

Start from the data. Keep rounding and permissions in one place. Prefer boring technology when the domain is already sharp. Leave decisions written down so the next pass does not have to guess.

If you have a product that needs to be correct more than it needs to be loud, write me.
